# 漢字・イラスト マッチング学習アプリ（試作）

小学1年生で学習する漢字80字と、カラーのシンプルな絵記号を3択でマッチングするiPad向けWebアプリです。80字は10字ずつ、8つのセットに分けています。

## 使い方

1. `index.html` をSafariなどのブラウザで開く。
2. ホーム画面で、取り組む10字のセットを選ぶ。
3. 大きく表示された漢字に合うイラストを選ぶ。
4. 正解すると、大きな赤い「○」が1秒間表示されて次の問題へ進む。
5. 10問を終えると「先生をよんでください」と表示される。
5. 教師は画面右下の何も表示されていない場所を約1秒長押しし、教師用画面を開く。

## 教師用画面

- 試作版のパスコードは `2580` です。
- 取り組んだ10字の中からランダムに1字を表示し、口頭で読みを確認します。
- 日付・時刻・セット名ごとに、各漢字の初回正誤と誤答回数を表示します。
- 記録はそのiPadのSafari内だけに保存されます。外部サービスやGitHubには送信しません。
- 「今日の記録を消去」「すべての記録を消去」は、教師用画面でのみ実行できます。

## 注意

- パスコードは生徒の誤操作を防ぐ簡易ロックです。GitHub Pagesのような公開サイトで厳重な成績保護をする仕組みではありません。
- SafariのWebサイトデータを消去したり、iPadを初期化・交換したりすると記録は消えます。
- 試作のイラストは端末標準のカラー絵記号です。公開版で「いらすとや」の素材に差し替える場合は、利用条件を確認してください。
